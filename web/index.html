Credits & thanks

None of this is ours alone.

This project got an HP Reverb G2 running at 90 Hz on Linux, with real 6DoF head tracking and working games. Almost all of the hard parts were already solved by other people, in the open, for free. This page says who, and — specifically — what of theirs we leaned on.

Every name and number below was read out of the actual source trees and patch files, not from memory. How, exactly, is at the bottom.

The runtime

Monado

Collabora and contributors BSL-1.0 gitlab.freedesktop.org/monado/monado

The open-source OpenXR runtime. It is the entire reason a Windows Mixed Reality headset can be spoken to from Linux at all.

What we used: the wmr driver — HID protocol, camera streaming, display activation, controller input — plus the compositor's Wayland direct-mode path, which is what actually leases the headset's DRM connector and takes the 90 Hz mode. Our fourteen patches are changes to this, not a replacement for any of it.

Most changes to the WMR driver, upstream: Jan Schmidt, Jakob Bornecrantz, Mateo de Mayo, Rylie Pavlik, Nima01, Christoph Haag, Moshi Turner, Linus Lüssing, Simon Zeni, Beyley Cardellio, Dan Weatherford, Nova King.

Constellation tracking

in-tree in Monado BSL-1.0

Optical tracking of a controller's LED constellation using the headset's own cameras — blob detection, correspondence search, pose solving.

What we used: all of it. Our 6DoF-controller work is wiring this existing tracker to the G2's cameras and LED model; we are writing the plumbing, not the tracker.

Written by: Beyley Cardellio, with a contribution from Christoph Haag. The idea of applying it to WMR specifically comes from Jan Schmidt's dev-constellation-controller-tracking work.

Basalt (Monado fork)

fork by Mateo de Mayo original by Vladyslav Usenko and Nikolaus Demmel (TUM) BSD-3-Clause

Visual-inertial SLAM. The fork adds the VIT interface Monado talks to.

What we used: every bit of real 6DoF head tracking in this project. Measured on our hardware: 4.04 m of coherent trajectory over 59 s of movement, against 2–4 cm of drift with the headset sitting still.

Most changes: Vladyslav Usenko, Mateo de Mayo, Nikolaus Demmel, Mattis Krauch, Bruno Zanotti, David Schubert.

The application layer

OpenXR-SDK-Source

The Khronos Group Apache-2.0 github.com/KhronosGroup/OpenXR-SDK-Source

The OpenXR loader, and hello_xr — the reference sample.

What we used: hello_xr is the skeleton our 360°/VR180 photo and video player grew out of. Thirteen patches deep, its session handling, action bindings and Vulkan plumbing are still doing the work underneath.

Most changes to hello_xr: Rylie Pavlik, utzcoz, Bryce Hutchings, Christoph Haag, Yin Li, Aaron Franke.

xrizer

Supreeeme and contributors GPL-3.0 github.com/Supreeeme/xrizer

OpenVR reimplemented on top of OpenXR, in Rust.

What we used: this is what lets real OpenVR games run against Monado without SteamVR. Every game session this project has ever had went through it.

Most changes: Shawn Wallace, Sapphire, knah, Mats Huesmann, galister, Orion Moonclaw.

The display path

NVIDIA open-gpu-kernel-modules

NVIDIA MIT / GPL-2.0 github.com/NVIDIA/open-gpu-kernel-modules

The open kernel modules. Being able to read and patch the display driver is the only reason the 90 Hz bug was findable at all — on a closed driver this project would have ended at "it doesn't work, we don't know why".

What we used: the whole modesetting path, and specifically nvkms's EDID handling, where the colour-depth clamp that kept the panel dark at 90 Hz turned out to live.

The Project-VR patches for 595-open

Ashish Kumar Singh

Three patches this project builds directly on top of: DisplayID/DSC/VSDB spec-correctness fixes, enabling Wayland DRM-lease of VR HMDs, and forcing the maximum DP link config for the G2.

Why it matters here: the DRM-lease patch is load-bearing. Without it there is no Wayland lease path at all — no wp_drm_lease_device_v1, no non-desktop=1 connector, and the entire launch chain this project automates would not exist. Our own contribution to the display path is one further patch on top of these.

And the ones without a repository line

The NVIDIA developer forum and the Linux VR Adventures community read a long bug report and pushed back on it. One of those corrections caught a claim that was simply wrong — that an upstream pull request had been merged when it was still open. Being contradicted in public is a gift; it is in this project's history as a correction, not a footnote.

Every person who filed a Reverb G2 bug against Monado, posted a kernel log of a dying cable, or answered a question about DRM leasing in a mailing-list thread that ended up in a search result at 3 in the morning. There is no way to enumerate you. It was still your work.

How these lists were made

Contributor names come from git shortlog -sn run against the specific subdirectory each project contributed to — the WMR driver, the constellation tracker, hello_xr — at the upstream commit our work branches from, so our own commits are excluded. Ordering is by number of commits, which measures volume and nothing else: it is not a ranking of importance, and plenty of decisive work is one commit long. Licenses were read from each tree's own LICENSE file or SPDX-License-Identifier headers.

Names are listed as they appear in git authorship. If yours is wrong, misspelled, or you would rather not be listed, open an issue and it gets fixed.

Being named here does not mean endorsing this project, reviewing it, or having any connection to it beyond the work of yours that we used.
