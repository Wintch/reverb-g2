# Steam launch options, per title

Generated by `scripts/backup-steam-config.sh` — **do not hand-edit**, it is overwritten.

Every OpenVR title needs the same three variables to reach Monado from inside Steam's
pressure-vessel container. They are not about the game: `XR_RUNTIME_JSON` picks the
runtime, `IPC_IGNORE_VERSION` skips the IPC version check, and
`PRESSURE_VESSEL_FILESYSTEMS_RW` exposes the Monado socket inside the sandbox.
Without them a title fails with `ERROR_RUNTIME_UNAVAILABLE` or a
"VR HMD not found" popup — which reads exactly like a compatibility problem and is not.

**Per-title tuning belongs here too**, not only the plumbing: engine cvars passed as
launch options can be worth a large fraction of the framerate (the user's own example:
Half-Life: Alyx, where forcing fog and LOD settings from the launcher is what made it
playable). A title can "work" and still be leaving half its performance unclaimed.
